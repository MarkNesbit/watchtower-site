# WT-ACTION-IDENTITY-001C5 — Administrative lifecycle conversion

Cancellation, formal brief and due-date amendments, reissue and acceptance takeover now resolve callers through C1 and record C2–C4 Auth/Profile/Membership history attribution. Administrative changes use the Raiser/PM/PO/Delivery Manager authority helper. Takeover is deliberately narrowed to active Project Manager, Product Owner or Delivery Manager assignments and rejects Actioner overlap.

The profile-keyed Action responsibility storage remains the 001D compatibility contract. Combined release validation still requires supported Cloudflare/CI build execution and production-shaped split-ID manual acceptance; local workerd cannot run on the available macOS 12.6 runtime.

## Resolver precedence follow-up

Production-shaped investigation found retained legacy equal-ID Profiles alongside explicit invitation-linked Profiles for the same Auth user, in different workspace histories. The resolver now gives a unique explicit `profiles.auth_user_id` link precedence and uses the equal-ID fallback only when explicit linkage is absent. This preserves fail-closed explicit and workspace-membership ambiguity handling without merging or changing production identity data.
