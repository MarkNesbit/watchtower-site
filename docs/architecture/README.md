# Watchtower Architecture Decisions

These Architecture Decision Records (ADRs) are the source of truth for platform architecture.

## Reading Order

1. ADR-000 Foundation Decisions
2. ADR-001 Authentication and Identity Model
3. ADR-002 Workspace and Membership Model
4. ADR-003 Project Domain Model
5. ADR-004 Security and Access Control Model
6. ADR-005 Data Ownership and Entity Relationships
7. ADR-006 Data Ingestion and Source-of-Truth Strategy
8. Timeline Foundation Architecture

## Rule

Implementation should follow these ADRs.

Where implementation requirements conflict with an ADR, a new ADR should be created rather than silently changing the architecture.
